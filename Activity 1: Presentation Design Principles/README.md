# Activity 1: Presentation Design Principles

## Short Description

<p align="justify">
This activity focused on applying the basic principles of presentation design by creating a promotional poster for a Free Coffee event at Arrupe Hall, Booth 7. It involved using appropriate typography, color combinations, illustrations, visual hierarchy, and layout to create an attractive and informative design that effectively communicates the event details.
</p>

## What Have I Learned?

<p align="justify">
Through this activity, I learned that an effective design is not only about making something visually attractive but also about presenting information clearly and organizing each element properly. I gained an understanding of how typography, color combinations, visual hierarchy, and spacing work together to make a poster more appealing and readable. One challenge was arranging the text and illustrations without making the poster look overcrowded, which required careful placement and balancing of the design elements. This activity helped me become more attentive to details and more confident in expressing creativity through visual design. I can apply these principles in creating future presentations, promotional materials, and other digital content.
</p>
