# Activity 1: Presentation Design Principles

## Short Description

This activity focused on applying the basic principles of presentation design by creating a promotional poster for a Free Coffee event at Arrupe Hall, Booth 7. It involved using appropriate typography, color combinations, illustrations, visual hierarchy, and layout to create an attractive and informative design that effectively communicates the event details.

## What Have I Learned?

Through this activity, I learned the importance of visual hierarchy, proper typography, color combinations, and balanced layouts in creating an effective design. I also learned how to combine text, illustrations, and visual elements to make a poster more appealing while keeping the information clear and readable. One challenge I encountered was organizing the different design elements without making the poster look overcrowded, which I addressed by arranging the text and illustrations carefully. This activity improved my creativity and attention to detail. In the future, I can apply these design principles when creating presentations, promotional materials, and other digital content.
