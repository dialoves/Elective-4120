# Activity 3: Social Media Infographics & Project Documentation

## Short Description

This activity focused on creating a social media infographic and preparing project documentation for a proposed technological solution. The infographic introduced **TRAFFIX: A Smart Traffic Monitoring and Management System**, which aims to improve traffic monitoring and information sharing in Davao City. The project documentation discussed the traffic congestion problem, its causes and effects, the proposed technological solution, and its expected impact. It also involved presenting important information through an organized and visually appealing infographic.

## What Have I Learned?

Through this activity, I learned how to transform complex information into simple, understandable, and visually engaging content through infographics. I also gained experience in identifying real-world problems, researching relevant information, and proposing technology-based solutions through proper project documentation. One challenge was organizing the technical details of traffic congestion and the proposed TRAFFIX system into concise and readable content, which I addressed by arranging the information into clear sections and using visual elements to highlight important points. This activity improved my research, critical thinking, information organization, and digital design skills. In the future, I can apply these skills when developing project proposals, presenting research findings, and creating informative digital materials.
