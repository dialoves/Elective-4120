# Activity 3: Social Media Infographics & Project Documentation

## Short Description

<p align="justify">
This activity focused on creating a social media infographic and preparing project documentation for a proposed technological solution. The infographic introduced TRAFFIX: A Smart Traffic Monitoring and Management System, which aims to improve traffic monitoring and information sharing in Davao City. The project documentation discussed the problem of traffic congestion, its causes and effects, the proposed technological solution, and its expected impact. It also involved presenting important information through an organized and visually engaging infographic.
</p>

## What Have I Learned?

<p align="justify">
Through this activity, I learned how to turn information gathered from research into an infographic that is easier for people to understand. I also realized that creating an effective infographic requires more than adding pictures and text because the information must be accurate, relevant, and arranged in a way that communicates the main message clearly. One challenge was organizing the information about traffic congestion and the proposed TRAFFIX system without making the infographic too crowded. I addressed this by selecting the most important details and presenting them through sections, illustrations, and short explanations. Working on the project documentation also helped me understand how technology can be proposed as a practical response to real-world problems. I can apply these skills in presenting research findings, developing project proposals, and creating informative materials in the future.
</p>
