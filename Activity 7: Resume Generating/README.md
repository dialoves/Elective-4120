# Activity 7: Comparative Resume Generation Using Multiple LLMs

## Short Description

<p align="justify">
This activity focused on comparing the resume-generation capabilities of two Large Language Models (LLMs), ChatGPT and Claude AI. Using the same prompt containing my personal information, educational background, clinical nursing experience, skills, and certifications, both tools were asked to create a professional one-page nursing resume. Their outputs were evaluated based on structure, clarity, formatting, and overall quality. The activity also involved examining their differences to determine which AI-generated resume better followed the given instructions and presented the information in a professional manner.
</p>

## What Have I Learned?

<p align="justify">
Comparing the two generated resumes showed me that different AI tools can produce noticeably different results even when given exactly the same instructions. ChatGPT provided organized and relevant content, but its output extended to two pages instead of the requested one-page format. Claude AI, on the other hand, presented a more compact layout with blue headings and divider lines, making it easier to identify the different sections. This comparison helped me realize that choosing an AI tool should not be based only on how quickly it generates a document, but also on how well the output meets the intended requirements. I also learned the importance of checking personal information, educational details, and qualifications rather than relying entirely on AI-generated content. In future applications, I can use these tools as starting points when preparing professional documents while making sure that the final output accurately represents my qualifications and experience.
</p>
