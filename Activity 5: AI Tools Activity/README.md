# Activity 5: AI Tools Activity

## Short Description

<p align="justify">
This activity focused on exploring how artificial intelligence tools can generate images based on written prompts. It involved creating an image of a Filipino food table using an original prompt, "Create a Filipino food table," and comparing it with another output generated using a more detailed and specific prompt. The improved prompt included particular Filipino dishes, traditional decorations, table arrangements, and a Filipino fiesta theme. The activity demonstrated how the quality and clarity of instructions can influence the results produced by AI tools.
</p>

## What Have I Learned?

<p align="justify">
I realized that the way we communicate with AI greatly affects the results it generates. When I compared the two images, I noticed that the original prompt produced a general representation of Filipino food, while the improved prompt resulted in a more detailed, organized, and culturally representative buffet setup. This helped me understand the importance of being specific when writing prompts, especially when describing the subject, arrangement, visual style, and other details I want to see in the output. One challenge was deciding which details to include in the improved prompt, so I addressed this by clearly describing the dishes, decorations, materials, and overall presentation I wanted. I also learned that even with detailed instructions, AI may not follow every request perfectly, so its output still needs to be reviewed. I can use this skill in future academic activities, presentations, and other tasks where AI tools can help communicate ideas visually.
</p>
