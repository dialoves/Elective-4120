# Activity 2: Personal Branding

## Short Description

This activity focused on developing a personal brand identity by creating a logo, color palette, typography set, and branding materials for a flower studio named **Peonydia**. The design featured a floral-inspired concept using soft and elegant colors, complemented by carefully selected fonts to establish a consistent and recognizable brand identity. It also included a brand contact page presenting the studio's information and social media details.

## What Have I Learned?

Through this activity, I learned how to develop a cohesive brand identity by combining visual elements such as logos, color palettes, typography, and layout. I gained a better understanding of how colors and fonts communicate a brand's personality and create a consistent visual impression. One challenge was choosing colors and fonts that complemented each other while maintaining the elegant floral theme, which I addressed by creating a coordinated color palette and typography set. This activity helped improve my creativity, design skills, and understanding of personal branding. In the future, I can apply these skills when developing professional portfolios, business identities, and other digital branding materials.
